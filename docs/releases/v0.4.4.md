Windows installer: download `GeoLock_0.4.4_x64-setup.exe` and run it (no admin needed). It updates 0.4.x in place and keeps your library and models.

**New in 0.4.4**

- **Updates from inside the app.** GeoLock now looks for a new version when it starts. When there is one, an orange **Update** button appears at the bottom of the library. It shows what's new and the download size, and downloads only when you click **Download**. Then click **Install and restart**: GeoLock closes, installs the update, and opens again, keeping your library, settings and models. The installer is checked against the checksum published with the release before it runs.
- **Settings › Updates** has a **Check for updates** button and a switch to stop checking at startup. The check reads one small file from the GeoLock releases on GitHub and sends nothing about you or your photos.

This is the last version you need to install by hand. Later versions arrive through the Update button.
