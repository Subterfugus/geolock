Windows installer: download `GeoLock_0.4.3_x64-setup.exe` and run it (no admin needed). It updates 0.4.x in place and keeps your library and models.

**New in 0.4.3**

- **Look up sign text on OpenStreetMap (optional).** When GeoLock reads a shop, street or company name, it can search OpenStreetMap for where that name exists. A name found in only one or a few places pins the photo to them; common words like "Hotel" are ignored. It's off by default. Turn it on in Settings › Analysis › **Look up sign text on OpenStreetMap**. It sends the text only, never the photo, and needs internet.
- **Daylight as a latitude clue.** If the photo's EXIF has the time and time zone (most phones write both), GeoLock checks whether the sky is daylight or night. It then rules out places where the sun was down (or up) at that moment. A bright photo at 21:45 on a June evening can only be from the far north. It only kicks in near sunrise or sunset, and it's skipped for indoor photos.
