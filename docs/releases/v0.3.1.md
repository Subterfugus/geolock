Windows installer: download `GeoLock_0.3.1_x64-setup.exe`, run it (no admin needed) and open GeoLock from the Start menu. On first launch it downloads the CLIP model once (about 600 MB).

**Fixed in 0.3.1**

- **Ask Claude now finds Claude Code even when it is not on PATH.** Claude Code's Windows installer puts `claude.exe` in `%USERPROFILE%\.local\bin` and does not add that folder to PATH, so GeoLock said "Install Claude Code" although it was installed. GeoLock now also looks there (and in `%APPDATA%\npm` for the Codex CLI).
